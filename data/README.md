# Sample data (no API key needed)

These JSON files match the **Spotify API response shape**, so the same code that reads the real API can read these files.

- **`sample_saved_albums.json`** – Saved albums (replace the placeholder items with your top albums).
- **`sample_liked_songs.json`** – Liked tracks (optional).
- **`sample_playlists.json`** – Playlists (optional).

Use **`src/spotify_user_data_from_sample.ipynb`** to load and display this data without any API credentials. After Feb 11, use the main notebook with your real API keys to fetch live data.
